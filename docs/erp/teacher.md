# Class teacher & teacher manual

You see only your own classes. If you are the **class teacher** of a class you get the *Class Teacher Desk* menu as well.

## Daily work
| Task | Where |
|---|---|
| Mark attendance | Attendance → pick class and date → Present / Absent / Late / Leave → Save |
| Enter marks | Exams & Marks → exam → class and subject → type marks → Save (grades are calculated) |
| Write the class diary / homework | Class Diary → New entry. Parents and students are notified. |
| Upload a question paper | Question Papers → Upload. Keep it **private** until exam day, or set an automatic release time. |
| See your timetable | My Timetable |
| Post a notice to your class | Notices & Events → Post (audience is your class) |

Approved student leave is filled into the attendance register as **Leave** for you. Real marks are never overwritten.

## Class teacher desk
* **Leave requests**: parents apply, the request lands with you. Approve or reject with a note. The family is notified.
* **Change requests**: mobile, address, guardian name, blood group. Approve and the record updates at once. Name and DOB are routed to the admin instead.
* **Support tickets**: reply to parents, set *In progress / Resolved*. Parents see the live status.
* **Student deactivation**: from a student's profile you can ask the admin to deactivate a student.
* **Community**: you can pin and delete posts in your class.
* **Broadcast**: send a quick message to every parent in your class.

## Your own HR
My Leave & Payslips: apply for leave (admin approves) and open payslips once payroll is finalized.
